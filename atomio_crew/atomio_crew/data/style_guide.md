# Atom.IO voice and content rules
Derived from the GDD: a simple, addictive arcade .io game built on the Bohr atomic model, played on a phone held sideways.

## Voice
- **Arcade-punchy.** Short sentences, active verbs, second person ("you"). Read in one glance mid-run.
- **Real science, light touch.** Atom.IO has no story. Its "lore" is the real periodic table, so every flavor line is anchored in a TRUE fact about the element (use, discovery, property, name origin). One small wink or pun is fine; never a lecture.
- **The player IS the atom.** Talk about protons, electrons, shells, orbits, energy, evolving, fusing. Never call the player a hero, wizard, pilot or ship.
- **Upbeat, never mean.** Failure messages sting a little but always point at the next try.

## Hard rules (the critic enforces these)
1. **No invented lore:** no kings, empires, prophecies, chosen ones, villains, magic, ancient curses or named characters. Real scientists and places from element names are fine.
2. **Game numbers must match the GDD exactly:** HP = 10 per proton; evolution cost = 50 + 3 x current atomic number; failure chance = (-1 + 1.04015^(Z-1))%, and each failure lowers it by 0.5%; orbiting electron hit = 10, thrown electron hit = 20, enemy contact = 10; electron slots = atomic number; win at Oganesson (118).
3. **Never contradict the electron rule:** the player always keeps at least 1 orbiting electron and can only throw when holding more than one.
4. **Facts must be correct.** If unsure about a fact, use a safer, well-known one.
5. **Fit the UI.** Respect every character limit; landscape phone, small labels.
6. **Placeholders** are written in braces exactly as given (e.g. {element}) and only where allowed.
